# Insurance Policy Dashboard

## Overview
An interactive Power BI dashboard developed to analyze insurance policy data and present key business insights through data visualization.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Key Features
- Insurance policy analysis
- Customer analysis
- Premium and coverage analysis
- Claim amount analysis
- Interactive KPIs, filters, and slicers

## Objective
To transform insurance data into meaningful visual insights that support data analysis and informed decision-making.
